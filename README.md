# Selected Earlier Work

This repository is an archive of projects completed during my earlier studies, primarily as part of the Vocational Qualification in Information and Communications Technology at OSAO.

The projects include experiments and study work involving:

- C++
- Python
- PHP
- IoT and hardware-oriented solutions
- Telegram integration
- Information display systems

I began many of these projects without a formal background in programming and learned through experimentation, official documentation, Stack Overflow, testing and persistent problem-solving.

The repository represents an earlier stage of my technical development. The code has been preserved mainly for historical and educational purposes, so individual projects may contain outdated dependencies, incomplete documentation or implementation choices that I would approach differently today.

These projects are not presented as current best-practice reference implementations. Instead, they document my early interest in programming, electronics, IoT and learning by building practical solutions.

## Historical Context

These projects were created before LLM-assisted development became a regular part of my personal workflow. At the time, official documentation, Stack Overflow and hands-on experimentation were my primary development resources.

Looking back, the projects show where my programming journey began and how my approach to software development has developed over time.
